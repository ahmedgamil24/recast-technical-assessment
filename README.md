# Recast Designs – Technical Assessment

## Live Preview
🔗 https://recast-technical-assessment.vercel.app/

## Description
This project is a technical assessment for Recast Designs.  
It represents a fully responsive e-commerce product section implemented based on the provided Figma design (Desktop & Mobile).

The goal of this task is to demonstrate clean UI implementation, structured JavaScript architecture, and dynamic data handling without using any external frameworks.

## Tech Stack
- HTML5 (Semantic Markup)
- CSS3 (Responsive & Pixel-Perfect Layout)
- Vanilla JavaScript (Class-Based Architecture)

## Features
- Dynamic product rendering from local data (no hard-coded HTML)
- Class-based JavaScript structure for Products, UI, and Cart logic
- Interactive image gallery with thumbnails
- Add to Cart functionality with dynamic cart count
- Fully responsive design matching the Figma layout
- Deployed on Vercel for live preview
